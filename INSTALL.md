# 🚀 Инструкция по запуску на адресе 192.168.110.77

## Быстрый старт

### Шаг 1: Проверьте IP-адрес компьютера

**Linux/Mac:**
```bash
chmod +x check_ip.sh
./check_ip.sh
```

**Windows:**
```cmd
check_ip.bat
```

### Шаг 2: Запустите приложение

**Linux/Mac:**
```bash
chmod +x start.sh
./start.sh
```

**Windows:**
```cmd
start.bat
```

### Шаг 3: Откройте в браузере

```
http://192.168.110.77:5000
```

## Ручной запуск

Если скрипты не работают, выполните вручную:

```bash
# Установка Flask
pip install flask

# Запуск приложения
python app.py
```

## Если IP-адрес не совпадает

### Вариант 1: Изменить IP в коде

Откройте файл `app.py` и измените строку:

```python
if __name__ == '__main__':
    app.run(debug=True, host='192.168.110.77', port=5000)
```

Замените `'192.168.110.77'` на ваш реальный IP-адрес.

### Вариант 2: Настроить статический IP

**Windows:**
1. Панель управления → Сеть и Интернет → Центр управления сетями
2. Изменение параметров адаптера
3. Правый клик на подключении → Свойства
4. IP версии 4 (TCP/IPv4) → Свойства
5. Установите:
   - IP-адрес: 192.168.110.77
   - Маска подсети: 255.255.255.0
   - Основной шлюз: (ваш роутер, обычно 192.168.110.1)

**Linux:**
```bash
sudo nano /etc/network/interfaces
```

Добавьте:
```
auto eth0
iface eth0 inet static
    address 192.168.110.77
    netmask 255.255.255.0
    gateway 192.168.110.1
```

**Mac:**
Системные настройки → Сеть → Ethernet → Дополнительно → TCP/IP
- Настройка IPv4: Вручную
- IP-адрес: 192.168.110.77
- Маска подсети: 255.255.255.0
- Маршрутизатор: 192.168.110.1

## Доступ из локальной сети

После запуска приложение будет доступно:
- На основном компьютере: http://192.168.110.77:5000
- С других устройств в сети: http://192.168.110.77:5000

## Решение проблем

### Ошибка: "Cannot assign requested address"
IP-адрес 192.168.110.77 не принадлежит этому компьютеру. Настройте статический IP или измените адрес в app.py.

### Ошибка: "Address already in use"
Порт 5000 уже занят. Измените порт в app.py:
```python
app.run(debug=True, host='192.168.110.77', port=8080)
```

### Приложение не открывается с другого устройства
1. Проверьте брандмауэр (firewall)
2. Убедитесь, что все устройства в одной сети
3. Проверьте, что IP-адрес правильный: `ping 192.168.110.77`
