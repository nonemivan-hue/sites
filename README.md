# TorrentFinder - Поиск торрентов по тегам (Python/Flask)

Веб-приложение для поиска торрент-файлов по тегам, написанное на Python с использованием Flask.

## 🚀 Как запустить

### 1. Установите Python

Убедитесь, что у вас установлен Python 3.8 или выше:
```bash
python --version
```

Скачать Python: https://www.python.org/downloads/

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустите приложение

```bash
python app.py
```

### 4. Откройте в браузере

Перейдите по адресу: **http://localhost:5000**

## 📁 Структура проекта

```
├── app.py              # Основной файл приложения (Flask)
├── requirements.txt    # Зависимости Python
├── templates/
│   └── index.html      # HTML шаблон
├── static/
│   └── style.css       # Стили CSS
└── README.md           # Документация
```

## ✨ Возможности

- 🔍 Поиск по названию, категории и тегам
- 🏷️ Фильтрация по 28 тегам в 5 категориях (Категория, Качество, Язык, Жанр, Тип)
- 📊 Сортировка по сидам, загрузкам и дате
- 📋 Копирование magnet-ссылки в буфер обмена
- 📱 Адаптивный дизайн (мобильные устройства)
- 🎨 Тёмная тема

## 🛠️ Технологии

- **Python 3** — язык программирования
- **Flask** — веб-фреймворк
- **Jinja2** — шаблонизатор
- **HTML/CSS** — вёрстка и стили

## 📝 Примечание

Это демо-приложение с примерами данных. Для реального использования необходимо подключить базу данных или API торрент-трекеров.
