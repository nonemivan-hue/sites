# TorrentFinder - Поиск торрентов по тегам

Веб-приложение для поиска торрент-файлов по тегам с поддержкой возрастных ограничений.

## 🚀 Запуск на адресе 192.168.110.77

### Требования:
- Python 3.8 или выше
- Компьютер с IP-адресом 192.168.110.77 в локальной сети

### Установка и запуск:

1. **Установите зависимости:**
```bash
pip install flask
```

2. **Запустите приложение:**
```bash
python app.py
```

3. **Откройте в браузере:**
```
http://192.168.110.77:5000
```

### Доступ из локальной сети:

После запуска приложение будет доступно:
- На основном компьютере: http://192.168.110.77:5000
- С других устройств в сети: http://192.168.110.77:5000

## ✨ Возможности

- 🔍 Поиск по названию, категории и тегам
- 🏷️ Фильтрация по 33 тегам в 6 категориях:
  - Категория (Фильмы, Сериалы, Игры, Музыка, Программы, Книги, Аниме, Документальные)
  - Качество (4K, 1080p, 720p, HDR)
  - Язык (Русский, Английский, Мультиязычный)
  - Жанр (Боевик, Комедия, Драма, Ужасы, Фантастика, Триллер, Фэнтези, RPG, Стратегия, Шутер)
  - Тип (Remux, WEB-DL, BDRip, DVDRip, Repack)
  - **Возраст (18+, 16+, 12+, 6+, 0+)**
- 📊 Сортировка по сидам, загрузкам и дате
- 📋 Копирование magnet-ссылки в буфер обмена
- 📱 Адаптивный дизайн
- 🎨 Тёмная тема
- 🔞 Возрастные метки на каждом торренте

## 🔧 Настройка IP-адреса

Если нужно изменить IP-адрес, отредактируйте файл `app.py`:

```python
if __name__ == '__main__':
    app.run(debug=True, host='192.168.110.77', port=5000)
```

Замените `'192.168.110.77'` на нужный IP-адрес.

## 🔒 Безопасность

Приложение запускается в режиме разработки (`debug=True`). Для продакшн-использования:
- Отключите debug режим
- Настройте HTTPS
- Добавьте аутентификацию
- Используйте production WSGI сервер (Gunicorn, uWSGI)
